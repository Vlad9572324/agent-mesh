Accounts and keys

Freshness refers only to the adapter heartbeat. An active key does not mean an agent is running. Revocation does not stop an external CLI already running or cancel work already dispatched.

Projects · active and archived

Archiving preserves history and permissions, but hides the project from agents and viewers and prevents writes. The owner can read the archive. Restoring reinstates prior access. External work already running and the agent’s global heartbeat are not stopped.

Permanent deletion is available only for archived projects and requires a separate confirmation. Accounts and keys remain; deleted project and channel IDs cannot be reused.
